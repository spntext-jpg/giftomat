# Giftomat

Локальная браузерная студия для подготовки медиафайлов:

- GIF из изображений или кадров видео;
- многостраничные PDF-карусели для LinkedIn;
- сохранение HTML-документов в постраничный PDF;
- обрезка баннеров под точные размеры;
- пакетная оптимизация JPG и WebP с выгрузкой ZIP.

Изображения, видео и HTML обрабатываются в браузере и не отправляются на сервер. Установленная PWA сохраняет основной интерфейс и runtime-библиотеки для офлайн-работы.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Полная проверка перед коммитом

```bash
npm run verify
```

Команда последовательно выполняет typecheck, unit-тесты, smoke-проверки и production build.

## Проверяемые сценарии

1. Добавление изображений кнопкой, drag-and-drop и вставкой из буфера.
2. Удаление кадра, очистка проекта и индивидуальная задержка GIF-кадров.
3. GIF с сохранением ориентации первого кадра и контролем лимитов X.
4. Извлечение кадров из видео и добавление их в общий список.
5. PDF-карусель с выбором размера страницы и режима размещения.
6. HTML → PDF с локальным sandbox-предпросмотром.
7. Обрезка одного изображения или всей загруженной пачки.
8. JPG/WebP и ZIP из нескольких оптимизированных файлов.
9. Светлая и тёмная системные темы, desktop layout и мобильный drawer.
10. PWA/offline shell и обновление некэш-хэшированных runtime-файлов.
