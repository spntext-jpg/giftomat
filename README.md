# Giftomat

Локальная браузерная студия для подготовки медиафайлов:

- GIF из изображений, включая профиль 16:9 для X;
- многостраничный PDF для LinkedIn Document Posts;
- конвертация PNG/WEBP в оптимизированные JPG с пакетной выгрузкой ZIP.

Файлы обрабатываются в браузере и не отправляются на сервер.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Проверка перед коммитом

```bash
npm run verify
```

Отдельные проверки:

```bash
npm run typecheck
npm test
npm run smoke
npm run build
```

## Проверяемые сценарии

1. Добавление файлов кнопкой и drag-and-drop.
2. Удаление одного кадра и очистка проекта.
3. Исходный GIF с прежним поведением.
4. GIF 16:9 для X с ограничением 15 МБ.
5. PDF 1080 × 1350 для LinkedIn.
6. Один JPG и ZIP из нескольких JPG.
7. Светлая и тёмная системные темы.
8. Desktop layout без прокрутки страницы и mobile layout со стеком панелей.
